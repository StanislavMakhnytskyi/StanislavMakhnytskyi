### About me

I build fast, scalable frontend systems for companies that cannot afford to get it wrong. Over the last 11 years I've worked on Mastercard's loyalty platform, an AI-driven financial crime detection tool, and TUI's booking systems used by millions of travelers.

I like turning messy legacy code into something a team actually enjoys maintaining. I care about performance, clean architecture, and making sure tests catch problems before users do.

- 🔭 Currently building enterprise dashboards and design systems at scale using **Nx** and **Module Federation**
- ⚡ Build optimized **Next.js** apps with the **App Router**, using **SSR** and **React Server Components** to cut load times and improve Core Web Vitals
- 🧠 Deep experience with **micro frontend architecture**, splitting large apps into independent, deployable pieces
- 🤖 Early adopter of **AI-assisted engineering**, using GitHub Copilot to speed up delivery without cutting corners on quality
- 💳 3 years in fintech: payments and financial crime detection
- 👥 2+ years leading small engineering teams (3-4 developers), owning architecture decisions and mentoring
