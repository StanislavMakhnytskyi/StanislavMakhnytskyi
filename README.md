### About me

I build fast, scalable frontend systems for companies that cannot afford to get it wrong. Over the last 11 years I've worked on Mastercard's loyalty platform (SessionM), an AI-based financial crime detection product, and TUI's booking systems — the world's leading tourism group.

I like turning messy legacy code into something a team actually enjoys maintaining. I care about performance, clean architecture, and making sure tests catch problems before users do.

- 🔭 Currently working on enterprise dashboards and shared component libraries at scale in an **Nx monorepo** with **Module Federation**
- 🧠 Deep experience with **micro frontend architecture** — Web Components at TUI, Module Federation today — splitting large apps into independently owned, deployable pieces
- 🤖 Rolled **GitHub Copilot** into my team's daily workflow: repo-level context, coding guidelines and architecture rules wired into VS Code
- 🧪 Raise the floor on quality — Jest, React Testing Library, Playwright, Storybook, lint/format/git-hook gates and Web Vitals checks in CI
- 💳 3 years in fintech: payments, loyalty, and financial crime detection
- 👥 4 years as Lead Software Engineer at EPAM, owning architecture and roadmap for teams of 3–4
- 🧩 On my own time: **Next.js (App Router, RSC)** and Module Federation side projects — see below
